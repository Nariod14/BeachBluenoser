# 🌊 Beach Bluenoser - Halifax Coastal Info App

BeachBluenoser is an Android application I assisted in developing during my tenure at Dalhousie University in Halifax, Nova Scotia. The app connects users with essential coastal data such as beach accessibility, amenities, safety notices, and environmental conditions, all delivered through a clean, responsive mobile interface.

## 📱 Features

- 📍 **Location-aware beach discovery**
- 🔄 **Real-time data synchronization** using Firebase Realtime Database
- 📊 **Optimized database structure** for low-latency performance
- 🔒 **Firebase Authentication** for user access and permissions
- 🗺️ **Interactive map view** with beach pins and quick summaries

## 🛠️ Tech Stack

- **Platform:** Android (Java/Kotlin)
- **Backend:** Firebase Realtime Database, Firebase Authentication
- **Development Tools:** Android Studio, Google Maps SDK

## 🧠 Project Goals

- Improve public access to local beach conditions and safety information
- Demonstrate efficient cloud-connected Android development
- Explore real-time mobile data synchronization techniques

## 🚧 Status

This project was developed during a 4-month placement at Dalhousie University (Jan–Apr 2024) and remains in a functional prototype stage. Future work could include user-submitted updates, weather integration, and multi-language support.
